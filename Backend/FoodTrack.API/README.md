Application destinée à éviter le gaspillage alimentaire.
Pour cela on scan les produits lors de l'achat ou chez soit ce qui permet d'avoir une trace des produits disponible chez soi.


Ce qu'elle fait pour le moment :
- Récupération d'un produit depuis un CodeBarre

Ce qui n'est pas géré pour le moment:
- La création d'une base de donnée au premier lancement de l'appli
- La gestion des erreurs

Ce qu'elle proposera en V1:
- Scan d'un produit avec un code barre
- Récupération du produit et enregistrement en base de données
- Affichage des listes des produits enregistrés

Ce qu'elle proposera en V2:
- "Gestion","Analyse" et autre ..... =)
